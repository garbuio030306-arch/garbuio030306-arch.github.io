The top chart shows one blended forecast line per maturity. VARX, XGBoost, Diebold-Li and the random walk are combined with weights set by how accurate each has been in the backtest. The thin dotted lines are the model range: the lowest and highest of the four raw model paths at each month. A wide gap means the models disagree. The 3m yield has no ensemble because the backtest never scored it, so it shows the VARX baseline. See individual model paths for each model on its own.

Individual model paths: VARX, XGBoost, Diebold-Li

Solid = history, dashed = VARX baseline, dotted = XGBoost, dash-dot = Diebold-Li, long-dash grey = random walk, thick solid = active lever scenario. Purple = 3m, blue = 2y, red = 10y. Only VARX responds to levers. XGBoost is shown at baseline, and Diebold-Li ignores levers by design, which is also why the ensemble is baseline-only.
